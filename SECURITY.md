# Security reporting

This is an educational local simulator. It reads a local JSON configuration and
writes reports; no network service, cloud account or credentials are needed.
Use trusted configuration paths and output directories. Do not run arbitrary
downloaded Python/MATLAB code without review.

For a suspected vulnerability, email `prajwalpratapyadav5@gmail.com` with the
affected version, reproduction and impact. Do not put credentials or private
data in public issues. Reporting is reviewed by the maintainer when available;
no response SLA is promised. Dependency updates and full-history/staged secret
scans help detect known issues but do not establish an absence of vulnerabilities.
